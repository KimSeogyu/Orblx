# The "row" lines must be exactly the shipped rows of that file, and each "partial" line a
# partial row of it. The sweep stops (exit 2) when they differ. Change both files together.
#
# row|NUMBER|FEATURE|PROOFS      One line for each shipped row. PROOFS: space list of proof
#                                names, or "-". A row with "-" makes the sweep fail.
# partial|NUMBER|FEATURE|PROOFS  A partial row whose proofs still run in the sweep. A failed
#                                proof fails the row. A partial row with no proof has no line.
# gate|NAME|TEXT|PROOFS          A gate with no shipped row of its own (it runs and can fail).
# proof|NAME|SCRIPT|ENV|IMAGES[|PASS ERE[|STEP LOGS]]
#   ENV: space list of NAME=VALUE ("-" for none). @BIN@ is the release orblx binary.
#   IMAGES: the image tags that the proof builds. The sweep removes them after the proof.
#   PASS ERE: the line that a pass needs (default: a proof_ok line).
#   STEP LOGS: a glob under the worktree for the logs that the proof writes to files of its
#     own. The sweep adds each file, whole, to the sweep log of the proof.
